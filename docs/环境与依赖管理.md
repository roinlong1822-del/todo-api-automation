## 6. 三连问:环境变量 / 前缀判断 / sqlite 跨线程(附实测)

### 6.1 `os.getenv(key, default)` 是什么

从**环境变量**读配置;变量不存在时返回 `default`。它让**同一份代码**靠环境切换数据库、密钥、环境名 —— 不用改代码。

```python
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./api_server.db")
```

实测行为:

| 情况 | 结果 |
|---|---|
| 变量不存在、没给默认 | `None` |
| 变量不存在、给了默认 | `sqlite:///./api_server.db` |
| 设置了环境变量 | 环境变量的值(`mysql+pymysql://…`) |
| 返回值类型 | **永远是 `str` 或 `None`**(不会自动转 int/bool) |

⚠️ **常见坑**:`.env` 文件**不会自动生效**。本项目里是显式传环境变量:

```bash
APP_ENV=test python -m uvicorn api_server.app.main:app --port 8000
```

### 6.2 `DATABASE_URL.startswith("sqlite")` 在判断什么

判断的是 **`os.getenv` 的最终返回值**(有环境变量用环境变量,没有用默认值)。默认值 `sqlite:///./api_server.db` 以 `sqlite` 开头 → 条件为真。

为什么这么判断:`DATABASE_URL` 是 **URL**,`scheme://` 前面那段就是**方言标识** —— `sqlite` / `mysql+pymysql` / `postgresql`。不同方言需要不同的连接参数。

更稳的写法(不用手动切字符串):

```python
from sqlalchemy.engine import make_url
make_url(DATABASE_URL).get_backend_name()     # 'sqlite' / 'mysql' / 'postgresql'
```

**sqlite URL 里斜杠数量的含义**(写错会把文件建到别处):

| URL | 含义 |
|---|---|
| `sqlite:///./api_server.db` | 相对路径 `./api_server.db` |
| `sqlite:////tmp/abs.db` | 绝对路径 `/tmp/abs.db`(四个斜杠) |
| `sqlite:///:memory:` | 内存库(进程结束即消失) |

### 6.3 `connect_args={"check_same_thread": False}` 是什么意思

直译没错 —— **"检查同一线程"**,这是传给 Python `sqlite3` 的开关,**默认 `True`**。

含义:默认要求**连接只能在创建它的那个线程里使用**,跨线程用会抛异常。实测:

```
默认(True)跨线程使用    : ProgrammingError: SQLite objects created in a thread
                          can only be used in that same thread...
check_same_thread=False : OK
```

**为什么 Web 服务要关掉**:uvicorn/FastAPI 用**线程池**处理请求,连接可能被不同线程使用;不关就会在并发时炸(FastAPI 官方文档对 SQLite 的示例也是这么写的)。

**关掉安全吗**:等于"把检查关掉、责任交给你"。我们的用法是**每个请求一个 Session**(`get_db`),不共享连接做并发写。SQLite 本身并发写能力弱,只适合测试/小规模;换 MySQL 时这个参数不需要(代码里已用 `else {}` 处理)。

> 记忆:这是 **sqlite 驱动层**的限制,不是 SQLAlchemy 的,也不是 HTTP 的。

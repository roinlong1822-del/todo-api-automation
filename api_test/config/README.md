# api_test/config/ — 多环境配置

**目标**:换环境只改一处(不碰用例)。

| 文件(待实现) | 内容 |
|---|---|
| `test.yaml` | 测试环境:base_url、超时、是否启用 mock |
| `dev.yaml` | 本地自建服务:base_url = `http://127.0.0.1:8000` |
| `loader.py` | 读配置 + 环境变量覆盖(`APP_ENV` 决定用哪份) |

**约定**:
- 配置里**不放明文账号密码** → 从 `.env`(本地)或 CI Secrets 读
- 用例里**不允许出现 URL、超时字面量**
